How this app works →
Light theme
Switches from the default dark look to a light one
Show Kanji content
The Kanji section isn't part of the course — on by default so nothing's hidden unless you turn it off
Half credit for hinted answers
If you use the hint/speak button before answering, a correct answer only adds half as much to your confidence score — wrong answers still cost the full amount
Work offline
Caches the app so it still opens with no signal — turn this on, then browse around a little while you've still got signal, before you actually need it offline
Trip vocabulary
Words specific to travelling to Japan (food, money, directions, emergencies, tourist phrases) rather than course content — adds a "Trip" pill on its own row under Vocab. Off by default so it doesn't clutter things for anyone not travelling
Activate Andrew mode
Personal staging area for whatever's being tried out next, before it's decided whether it becomes core or its own gated tier (like Trip vocabulary above) — currently empty, adds an "Andrew" pill on its own row under Vocab when there's something to show
Export my scores
Copies your saved drill scores as text — for troubleshooting only
